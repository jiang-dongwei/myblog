## 人工验证记录 [HVR-S5-001]

**验证类型**: Windows 蓝牙与浏览器 Gamepad API 实机测试
**所属步骤**: S5-D / S5-E / S5-F
**验证时间**: 2026-08-13
**结论**: 失败，进入返工

| 名称要求 | PS5及非Xbox模式恢复原名，只继续修改Xbox模式 |

### AI 初步分析

1. Xbox 名称长度为20字节；当前Legacy Advertising同时放入Flags、Appearance、
   HID UUID和Complete Name，合计超过31字节，`ble_gap_adv_set_fields()`会失败，
   因而Xbox模式不可发现。
2. Web Gamepad的`mapping`由浏览器根据VID/PID和HID输入布局选择，不由蓝牙
   名称决定。项目VID/PID `1209:2040`不在Chromium Windows标准映射表中。
3. 当前Xbox描述符的按钮Usage编号和轴Usage位置也不符合Chromium
   `MapperXboxBluetooth`所期待的Xbox One S Bluetooth原始布局。

### 共同决策

```
决策: 失败，S5返工
解决方向:
1. 所有Profile恢复FP12Slim-C6蓝牙名称，修复广播31字节限制。
2. Generic/Keyboard/PS描述符和身份不再继续变化。
3. 仅Xbox Profile采用浏览器可识别的Xbox Bluetooth VID/PID与原始HID布局。
4. 保持无振动实现。
```
