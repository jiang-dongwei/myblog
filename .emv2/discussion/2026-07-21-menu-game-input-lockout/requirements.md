# 需求确认: 菜单期间锁定游戏交互

讨论ID: `2026-07-21-menu-game-input-lockout`

## 已确认行为

- GP30 长按真正打开菜单的同一轮开始锁定游戏交互；长按判定之前保持原行为。
- GP2～GP20 不得在菜单期间影响 USB 或 BLE 游戏输入。
- GP19 继续作为菜单 `BACK` 使用；只屏蔽它对应的游戏 `A2`。
- GP20 不得在菜单期间切换 Turbo 按键、调整速度或产生连发输出。
- 菜单期间取消正在运行的宏，禁止新宏和普通/重启热键。
- 进入菜单时主机必须收到 neutral 以释放此前按住的按键。
- 退出菜单后不重放旧按键；原始 GPIO 和消抖 GPIO 全部释放并稳定 30ms 后才恢复。
- OLED 菜单与 RGB 渲染继续运行。

## 传输职责

- RP2350：菜单锁状态、USB neutral、本地 Turbo/宏/热键保护。
- ESP32-C6：读取 `FP` 菜单锁标志，在 BLE HID 最终出口执行 neutral 与 release-to-rearm。
- 本次不修改 ESP32-C6 源码，只提供实施协议文档。
