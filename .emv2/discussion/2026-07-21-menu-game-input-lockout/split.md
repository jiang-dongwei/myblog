# 需求拆分: 菜单期间锁定游戏交互

讨论ID: `2026-07-21-menu-game-input-lockout`
步骤编号: `S24`

## 子系统

1. **菜单锁存状态机**：菜单打开时锁定，退出后等待 GP2～GP20 全部释放再解锁。
2. **RP2350 USB 输出门控**：USB 游戏报告在锁定期间保持 neutral。
3. **RP2350 本地输入副作用保护**：暂停 Turbo、宏和热键处理。
4. **ESP32-C6 BLE HID 锁定协议**：RP2350 在 `FP` 帧发布锁状态，由 ESP32 在 BLE HID 最终出口执行 neutral。
5. **验证**：覆盖 USB、蓝牙、GP19 BACK、GP20 Turbo 和退出粘键。

## 用户确认

用户确认采用 RP2350 与 ESP32-C6 分层的混合方案；本次只修改 RP2350，并提供共享文档交给 ESP32 侧 AI。
