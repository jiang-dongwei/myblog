# 头脑风暴: BQ27220 启动回读与电流校准

## 1. 修复前证据不能丢失

- 启动先完成完整回读，再决定是否写入。
- 同时保存修复前值、目标值和修复后值。
- OLED 通过 `OK/FIX/BAD` 区分原本一致、修复成功和失败。

## 2. 避免普通重启破坏学习状态

- Battery Low 和 EDV 使用选择性写入。
- 普通配置差异不写 FCC。
- 只有确认 BQ27220 RAM 恢复默认时，才允许恢复 650 mAh FCC 初始基线。

## 3. F4 校准值不能按普通 float 写入

- CC Gain 和 CC Delta 同时保留 4 字节原始值和解码显示值。
- 第一轮只读；实际数据采集后再计算、编码、写入和逐字节验证。
- 任一步失败时停止后续写入并保留原值。

## 4. 菜单分页

- 新增独立 `BATTERY_INFO` 层级，避免复用静态 INFO 页后失去拨轮翻页能力。
- Core0 只维护菜单页码，Core1 读取固定大小诊断快照并绘制。
- 页面手动切换，不使用自动轮播。

## 5. 分阶段校准

- 第一轮实现回读、修复和显示。
- 用户在 0 mA 与 318 mA 条件下记录多组稳定数据。
- 第二轮根据实测值固化 CC Gain/CC Delta，再完成放电回归。
