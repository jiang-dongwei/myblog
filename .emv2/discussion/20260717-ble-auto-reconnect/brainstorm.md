# 头脑风暴: BLE 自动重连

## 难点总结

| 难点 | 风险 | 决策 |
|------|------|------|
| 持续广播耗电 | 低 | 维持 100-200ms 广播间隔 |
| 非绑定设备连接 | 无 | 安全配置不变 |
| 广播意外停止 | 低 | 扩展保活逻辑为全时段 |
| 首次开机无 Bond | 无 | 无需处理 |
| GPIO13 清 Bond | 无 | 行为不变 |

## 改动清单（3处）

1. `start_advertising()` 移除 `pairing_window_active()` 条件
2. `pair_button_task` 删除窗口过期停止广播的代码
3. `pair_button_task` 兜底保活扩展为全时段
