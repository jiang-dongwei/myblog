# 需求拆分: 定向广播 + 断连空闲降速

## 子系统

### 1. 定向广播触发（按键活动 → 定向广播）
- 类型：状态机
- 简述：断开状态下，RP2350 发送手柄按键数据 → ESP32 检测到活动 → 切换到定向广播（BLE_GAP_CONN_MODE_DIR），用配对主机地址定向发送，主机快速发现

### 2. 断连空闲超时 → 慢广播
- 类型：状态机
- 简述：手柄断连后 1 分钟没有成功重连 → 广播间隔降为 200ms（用户确认：不要太慢）

### 3. RP2350 活动检测（已有，需增强）
- 类型：通信
- 简述：已有 `s_last_uart_activity_tick`，断开状态下需触发定向广播切换
