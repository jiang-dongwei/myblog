# 需求确认

讨论ID：`2026-07-31-webconfig-fightpad-branding`

## Logo

- 图形使用 S26 启动图中同一个方框 R Logo。
- 从 128×64 的 1-bit 字模点亮区域生成透明 SVG，保持像素轮廓一致。
- Web 主色沿用现有 `#ec008c`。

## FIGHTPAD 字标

- 导航栏右侧显示大写 `FIGHTPAD`。
- 字体使用本机粗黑无衬线字体栈、粗体和斜体，保持原粉色品牌字标的视觉方向。
- Logo 与文字为独立元素，方便缩放、辅助功能和后续品牌调整。

## 品牌范围

- 更新导航栏标题与替代文本、所有语言的共享品牌名和首页欢迎标题。
- 更新页面 title、description、favicon 引用和 manifest 名称。
- 不全局替换协议说明、固件功能或兼容性文本中的 `GP2040-CE`。
- 按项目约定不运行 Web 或固件编译，由用户完成构建和设备页面视觉确认。
