# 头脑风暴

讨论ID：`2026-07-31-fightpad-default-splash-logo`

## 方案比较

### 方案 A：逐台通过 Web Config 上传

- 优点：无需重新编译。
- 缺点：量产操作重复，容易漏配，不适合作为出厂默认值。

### 方案 B：修改通用 GP2040-CE 默认启动图

- 优点：实现直接。
- 缺点：会影响其他板卡配置，不符合板级隔离要求。

### 方案 C：在 Fightpad12Slim BoardConfig 覆盖 `DEFAULT_SPLASH`

- 优点：符合项目已有板卡惯例，只影响目标产品，适合统一量产固件。
- 注意：已写入持久化配置的设备仍会优先使用保存值。

## 决策

采用方案 C。把 `zimo.TXT` 的 64 行嵌套字模扁平化成 1024 字节 C 宏，并保持原有静态模式和 3 秒时长。
