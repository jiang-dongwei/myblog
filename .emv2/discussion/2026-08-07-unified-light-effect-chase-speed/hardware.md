# 硬件对齐

讨论ID：`2026-08-07-unified-light-effect-chase-speed`

## 已有硬件

- 主控：RP2350B。
- Key 灯链：GP22，12 颗 WS2812，PIO2 / SM1。
- Base 灯链：GP40，19 颗 WS2812，PIO2 / SM0。
- RGB 供电：GP24 控制 5V Boost。
- 菜单输入：GP30/GP31/GP32，GP19 返回。

## 新增硬件需求

- 无新增 GPIO。
- 无新增 LED、外设、通信接口、中断或 DMA。
- 不改变两条 WS2812 的灯珠数量、物理顺序、PIO 或状态机分配。

## 硬件兼容约束

- 两条灯链长度不同，同步定义为同模式、同色轮相位、同动画更新时间，而不是相同灯珠索引。
- GP22 的按键映射和 Flash 计时数组保持不变。
- GP40 的蓝牙状态临时覆盖保持独立。
- GP24 门控和 BQ27220 低电最终写入保护不变。
