# 需求确认

## GP30 短按手势

- 仅在拨轮菜单关闭时生效。
- 使用当前 GP30 五态按键状态机的短按确认结果，不恢复旧版灯光插件自行识别短按的逻辑。
- 长按阈值保持 `SCROLLWHEEL_LONG_PRESS_MS = 2000`，长按只进入或退出菜单，不切换灯光。
- 每次完整短按只切换一次。

## 灯光开关行为

- 第一次短按临时关闭 GP22 Key 灯链与 GP40 Base 灯链，并通过现有门控路径关闭 GP24 RGB 电源。
- 再次短按恢复关闭前的当前 Light Effect、颜色、亮度与 Key Flash 配置。
- GP30 开关通过独立字段写入 Flash；设备重启后恢复上次 GP30 开关状态。
- 菜单持久化的 `All OFF` 状态保持原语义，临时开关不创建默认灯效覆盖它。

## 优先级

1. `SOC <= 7%` 低电保护仍为最高优先级。
2. GP30 手动临时关灯时，普通灯效和 Key Flash 不得点亮灯链或请求 GP24 上电。
3. 蓝牙 Pairing/Connecting/Connected 临时灯效保持现有行为；需要显示时可临时点亮 GP40 并请求 GP24 上电，GP22 仍保持熄灭。
4. OLED 蓝牙状态提示不受手动灯光开关影响。
5. 蓝牙临时提示结束后，如果手动开关仍为关闭，灯光重新保持熄灭；手动恢复后普通效果继续按照原有优先级工作。

## 兼容范围

- 只针对 Fightpad12Slim 的现有 GP30、GP22、GP40、GP24 路径。
- 新增一个 Fightpad 灯光 protobuf 布尔字段；不修改 Web Config 或 ESP32-C6 固件协议。
