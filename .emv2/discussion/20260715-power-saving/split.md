# 需求拆分 — 降低功耗

## 拆分结果

### 1. CPU/SoC 电源管理
- 类型：控制
- 简述：CPU 频率动态调节（160MHz → 80/40MHz），启用 Light Sleep 模式在空闲时降低功耗

### 2. BLE 功耗优化 + 广播策略
- 类型：通信
- 简述：优化广播参数（广播间隔、TX 功率）和连接参数；修改广播策略：开机自动广播 N 秒 + GPIO13 手动触发广播

### 3. 外设功耗管理
- 类型：控制
- 简述：关闭/门控未使用外设时钟，UART 低功耗优化，GPIO 配置优化

### 4. FreeRTOS Tickless Idle
- 类型：状态机
- 简述：启用 Tickless Idle，减少系统定时器中断唤醒，调优任务周期
