# 子流程拆分: BQ27220 电量 SOC/FCC 稳定性

## S11-A: BQ27220 配置写入行为审计

- 所属子系统：BQ27220 配置与初始化
- 开发内容：
  1. 确认当前开机配置写入哪些 Data Memory 项。
  2. 重点确认 FCC 是否每次被写回 650。
  3. 保持正常 BQ 配置流程，不改 ESP32，不改 OLED 正常显示。
- 前置条件：无
- 验证方式：编译通过，OLED 诊断显示配置状态不退化。
- 优先级：1

## S11-B: BQ27220 诊断读取补强

- 所属子系统：BQ27220 SOC/FCC 跳变诊断
- 开发内容：
  1. 确认现有 OLED 诊断页足够显示 SOC、Voltage、Current、FCC、状态码。
  2. 必要时只补 BQ27220 侧状态读取，不新增日志，不新增 OLED 页面级交互。
  3. 不改 ESP32 相关代码。
- 前置条件：S11-A 完成
- 验证方式：OLED 可人工记录关键字段。
- 优先级：2

## S11-C: SOC/FCC 跳变实机复测

- 所属子系统：实机验证流程
- 开发内容：
  1. 使用现有 OLED 诊断显示进行人工记录。
  2. 记录 75%、52%、7%、5%、0%、首次重启后 FCC 等关键点。
  3. 判断 FCC 回 650 是否与 RP2350 重启/配置写入相关。
- 前置条件：S11-A、S11-B 完成
- 验证方式：形成实机记录表，至少包含 SOC、Voltage、Current、FCC、状态码、是否重启。
- 优先级：3

## S11-D: 低电灯效侧降耗策略评估

- 所属子系统：低电压与系统重启保护
- 开发内容：
  1. 只评估 RP2350 灯效侧降耗策略。
  2. 不改 OLED 页面，不改 ESP32，不直接关 GP24。
  3. 低电时仍保持正常 BQ 配置流程。
- 前置条件：S11-C 完成
- 验证方式：观察低电时灯乱闪/系统反复重启是否缓解。
- 优先级：4

## 约束汇总

- 不实现串口日志、Flash 日志或 ESP32 侧日志。
- 不改 ESP32 相关代码。
- 不改 OLED 正常显示。
- 保持正常写 BQ 配置流程。
- BQ27220 是唯一可信电量来源；GP41 ADC 不在本阶段作为改动目标。
