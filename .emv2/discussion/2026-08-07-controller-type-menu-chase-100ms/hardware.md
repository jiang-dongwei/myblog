# 硬件对应

## 菜单输入

- GP31 / GP32：继续承担拨轮菜单上下滚动。
- GP30：菜单关闭时切换普通灯光允许状态；菜单打开时作为确认键。
- Controller Type 不新增按键，不修改现有 GPIO 配置。

## 灯光输出

- GP22 按键灯链和 GP40 底部灯链继续共享普通 Light Effect 的 Chase 步进状态。
- 普通 Chase 步进时间改为 100ms。
- 蓝牙状态灯使用的独立 Chase 保持 50ms。

## USB 与存储

- 控制器模式保存到 RP2350 Flash 中的 `GamepadOptions.inputMode`。
- 切换不同模式并完成保存后重启 RP2350，使对应 USB 驱动和描述符重新加载。
- 重启会导致 USB 短暂断开并重新枚举。
- 本功能不修改 ESP32-C6 蓝牙 HID 模式，也不改变 PCB 接线。

## 认证边界

- PS4、PS5继续使用项目已有认证配置。
- 菜单不新增、不模拟、不绕过主机认证。
