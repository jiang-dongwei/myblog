# 子流程拆分: ESP32-C6 固件信息串口接收与菜单显示

讨论ID: `2026-07-13-esp32-firmware-info-uart`

## S13-A: UART RX 与固件帧状态机

- **所属子系统**: 通信
- **开发内容**: 让 UART RX 始终运行；实现 `0x46 0x49` 滑动同步、XOR、flag、seq、200ms 超时和溢出处理。
- **前置条件**: 无
- **验证方式**: 检查日志、坏帧、缺帧、乱序和完整帧路径。
- **优先级**: 1

## S13-B: Payload 解析与跨核快照

- **所属子系统**: 数据管理
- **开发内容**: 重组最大 256 字节 Payload，解析四个必需字段并向 Core1 原子发布完整快照。
- **前置条件**: S13-A 完成
- **验证方式**: 检查字段缺失、未知字段、长字符串和重复更新行为。
- **优先级**: 2

## S13-C: ESP32 固件信息菜单

- **所属子系统**: OLED 菜单显示
- **开发内容**: 显示 SDK、Plat、两行 Board、CPU；无数据时显示 `Coming to soon`。
- **前置条件**: S13-B 完成
- **验证方式**: 检查 21 列、8 行布局、字符串边界和 INFO 页导航。
- **优先级**: 3

## S13-D: 静态与实机验证

- **所属子系统**: 测试
- **开发内容**: 执行非构建静态检查；用户编译烧录后检查有效信息和无数据回退页面。
- **前置条件**: S13-A、S13-B、S13-C 完成
- **验证方式**: `git diff --check`、源代码审查和 OLED 实机观察。
- **优先级**: 4
