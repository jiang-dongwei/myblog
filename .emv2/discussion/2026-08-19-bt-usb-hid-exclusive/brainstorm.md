# 头脑风暴: 蓝牙档位 USB HID 互斥

讨论ID: `2026-08-19-bt-usb-hid-exclusive`

## 难点1: USB断开前的残留按键

- 直接断开可以让主机移除设备，但运行时切换时仍应尽量先提交一次中立报告。
- 方案: 复用现有中立报告门控；若报告已提交则立即断开，否则最多等待20ms，避免端点繁忙导致状态机无限等待。

## 难点2: 重新连接后的首个输入

- USB重新连接后 TinyUSB 重新枚举，现有驱动继续运行；USB断开期间不改描述符和控制器模式。
- USB切换由同一份已消抖 GP33 状态驱动，避免同一循环内连接状态与报告路由不一致。

## 难点3: Web Config可达性

- Web Config 使用同一 TinyUSB Device，但它不是普通游戏手柄模式。
- 方案: `configMode` 强制 USB 保持连接，不应用蓝牙档位断开策略。

## 选择方案

采用 TinyUSB 软件断开/重连，不采用 VBUS 自动强制 USB 模式，也不修改硬件供电路径。
