# 子流程拆分: 蓝牙档位 USB HID 互斥

讨论ID: `2026-08-19-bt-usb-hid-exclusive`

## S53-A: TinyUSB连接状态机

- 所属子系统: USB通信 / 传输状态机
- 开发内容: 启动时按 GP33 和 Config Mode 决定 USB 连接；运行时执行软断开和重连。
- 验证方式: 静态检查连接API只在状态变化时调用，Web Config分支始终连接。

## S53-B: 切换中立与边界隔离

- 所属子系统: 输入路由
- 开发内容: USB转BT时复用中立报告并设置有限等待；复用同一份GP33采样完成报告路由和USB连接控制。
- 验证方式: 静态检查 USB/BT、菜单输入锁和 Config Mode 分支。

## S53-C: 文档与非编译验证

- 所属子系统: 验证
- 开发内容: 更新板级行为说明，执行差异、空白、符号和调用路径检查。
- 验证方式: `rg`、`git diff --check` 和 `git diff`；构建烧录由用户完成。

## S53-D: 实机验证

- 所属子系统: 系统测试
- 开发内容: 用户构建烧录并验证蓝牙档位插PC不枚举USB手柄、USB档位重新枚举、Web Config和BOOTSEL可用。
- 验证方式: Windows设备列表、游戏控制器测试和Web Config访问。
